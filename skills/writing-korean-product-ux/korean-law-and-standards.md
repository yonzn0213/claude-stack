# 국내 법·공공 표준 중 앱·웹 화면에 걸리는 것

2026-11-10 조사. **법령**은 지켜야 하고, **지침**은 권고다. law.go.kr·krds.go.kr 본문은 자동으로 읽히지 않아 로펌·언론·지자체 자료로 교차 확인했다. 숫자에 [원문 미확인]이 붙은 것은 출시 전 원문을 한 번 본다.

## 1. 다크패턴 — 결제·구독·회원가입이 있으면 반드시 본다

**법령: 전자상거래법 개정, 시행 2025-02-14** (순차공개 가격책정만 2025-08-13까지 계도)

| 금지되는 것 | 화면이 해야 할 것 |
|---|---|
| 순차공개 가격책정 (제21조의2 ①1) | 첫 화면(배너 포함)부터 세금·필수 비용을 더한 **총액**을 보여 준다. 고를 수 있는 배송비·설치비는 예외 |
| 특정 옵션 미리 선택 (①2) | 회사에 유리한 옵션·추가 상품을 미리 체크하지 않는다. 배송지·결제수단 자동 입력은 괜찮다 |
| 잘못된 계층 구조 (①3) | 동의·거부, 가입·건너뛰기를 비슷한 크기·색·굵기로 나란히 둔다 |
| 취소·탈퇴 방해 (①4) | 가입보다 해지를 어렵게 하지 않는다. 가입과 다른 방법(전화만, 챗봇만)으로만 해지하게 하지 않는다 |
| 반복 간섭 (①5) | 이미 거절한 선택을 팝업으로 다시 묻지 않는다. 묻더라도 "7일간 보지 않기" 이상을 준다 |
| 숨은 갱신 (제13조 ⑥) | 정기결제 금액 인상·무료→유료 전환 전에 따로 동의를 받는다. 바뀌는 날·전후 가격·결제수단·해지 방법을 알린다. 답이 없으면 동의로 보지 않는다 |

**지침: 공정위 「다크패턴 방지를 위한 온라인 인터페이스 운영 가이드라인」 (2026-10-06, 13유형)**. 2023-07-31 「온라인 다크패턴 자율관리 가이드라인」(19유형)을 합친 최신판이다. 두 문서를 섞어 인용하지 않는다.
- 해지·탈퇴 버튼은 로그인 첫 화면이나 마이페이지처럼 **한 번 눌러 닿는 곳**에, 이름은 `멤버십 해지`, `회원 탈퇴`처럼 바로 알게. 설정·보안 메뉴 안에 숨기거나 해지 설문을 강제하면 방해로 볼 수 있다.
- 같은 팝업을 **2번 이상** 띄우면 반복이다. 거절 기록을 저장하고, 해지 의사를 밝힌 사람에게 다음 날 같은 팝업을 띄우지 않는다.
- 유료 전환·인상은 **30일 전**에 따로 동의를 받고, 동의가 없으면 결제가 안 되게 만든다. [원문 미확인]
- 할인 전 가격은 실제 판매 기록이 있는 값만. 돈 받은 후기는 표시하고, 나쁜 후기를 지우거나 순서를 조작하지 않는다.
- 숙박 도시세·리조트피처럼 현장에서 내는 돈도 원칙적으로 총액에 넣는다.

## 2. 개인정보 동의 화면

**법령: 개인정보 보호법 제22조, 시행령 제17조** — 자유로운 의사, 구체적이고 쉬운 문구, 동의 여부를 분명히 고를 방법. 홍보 연락, 민감정보, 보유 기간, 제3자 제공은 눈에 띄게 표시한다.

**지침: 개인정보보호위원회 「알기 쉬운 개인정보 처리 동의 안내서」 (2022-03-03)**
- 필요한 때에, 필요한 만큼만 묻는다. 가입할 때 한꺼번에 포괄 동의를 받지 않는다.
- 중요한 내용은 **9pt 이상이면서 다른 글자보다 20% 이상 크게**, 색·굵기·밑줄로 구분한다.
- `동의함` 체크박스를 미리 체크해 두지 않는다.
- 필수와 선택(마케팅 등)을 나누고, 선택을 거부해도 다음 화면으로 갈 수 있어야 한다.
- 2025-07 개인정보위가 슈퍼앱 점검에서 불필요한 필수 동의를 줄이라고 권고했다.

## 3. 접근성

**지침: 한국형 웹 콘텐츠 접근성 지침(KWCAG) 2.2 (2022-12-28)** — 4원칙·14지침·33항목. 장애인차별금지법의 접근성 의무와 웹접근성 품질마크 인증 기준이 이것이다. 모바일 앱은 「모바일 애플리케이션 접근성 지침 2.0」(2016)을 따로 본다.
- 글자와 배경 명도 대비 **4.5:1 이상** (큰 글자는 3:1)
- 누르는 대상은 **대각선 6.0mm 이상**, 주변 여백 확보 [원문 미확인]
- 1초에 3~50번 깜빡이는 콘텐츠 금지, 자동으로 소리 내지 않기, 자동으로 바뀌는 콘텐츠는 멈출 수 있게
- 시간 제한은 가능하면 두지 않고, 필요하면 늘리거나 끌 수 있게
- 이미지 대체 텍스트, 입력칸 라벨, 키보드 초점 표시

## 4. 정부 디자인 시스템 (참고용)

**지침: KRDS 범정부 UI/UX 디자인 시스템 (행정안전부, 배포 2024-02-29, 서비스 2025-01-16)** — 공공 서비스용이지만 민간도 참고할 만하다. https://www.krds.go.kr
- 컴포넌트 43개, 기본 패턴 11개, 서비스 패턴 5개. 개인정보 입력·동의·내용 확인·입력 폼·로그인·신청 패턴을 그대로 참고할 수 있다.
- 접근성은 WCAG AA 이상, 서체는 Pretendard GOV, 고대비 모드를 토큰으로 따로 둔다.
- 안내를 입력칸 placeholder에 넣지 않는다(입력하면 사라짐). 도움말은 입력칸 밖에.

## 5. 쉬운 말

- 국어기본법 제14조는 공공기관에 알기 쉬운 용어·문장을 쓰라고 한다(제재 없음). 국립국어원 「쉬운 공공언어 쓰기 길잡이」, 다듬은 말 약 2만 건.
- [참고, 민간 공공 UX 라이팅 가이드] 동의 화면 선택지는 `예/아니오` 대신 `동의함/동의 안 함`. 쉬운 말이 없으면 툴팁·도움말로 뜻을 준다. 예: `인감을 날인` → `인감도장을 찍기`, `소정의 급여` → `정해진 급여`.
