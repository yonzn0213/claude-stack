# 앱인토스 공식 출시 가이드 체크리스트

2026-11-10 사용자가 콘솔에서 복사해 준 원문을 줄였다. 원문은 "지속적으로 최신화"되므로 출시 전에 콘솔에서 다시 본다. 지키지 않거나 다크패턴이 보이면 검수가 승인되지 않고, 출시 뒤에 발견돼도 노출이 제한·중단된다.

## 비게임·게임 공통

**보안·안정성**
- 앱 브릿지(SDK API)를 짧은 시간에 과도하게 호출하지 않는다. 반복문·타이머·화면 갱신으로 같은 호출을 되풀이하지 않는다. → 저장 같은 호출은 모았다가 한 번에(디바운스), 백그라운드로 갈 때 바로 쓰기.
- 호출이 실패하면 재시도 횟수와 간격을 제한한다.
- `eval` 등 외부 코드 실행 금지.
- 토스 도메인 밖으로 이동하거나 그 콘텐츠를 렌더링하지 않는다(`window.location.replace`, 자사 도메인 WebView·iframe 금지).
- SSR 금지. CSR 또는 SSG만.
- WebSocket은 `wss://`만, API는 HTTPS만.
- 로그인 정보·결제 내역 등 민감 정보는 DB에 암호화해 저장. 개인정보를 서버로 보낼 때도 암호화 권장.

**UX**
- 들어오자마자 바텀시트(토스 로그인, 알림 동의 등)를 띄우지 않는다. 화면 전환 때 바텀시트로 행동을 강요하지 않는다.
- 모든 화면에서 나갈 방법이 있다. CTA만 보고 다음 일을 예측할 수 있다.
- 자사 서비스 이동이나 자사 앱 설치를 유도하지 않는다.
- 예상 못 한 순간에 전면 광고를 띄우지 않는다. 광고 클릭을 오인·강제하지 않는다.

**동작**
- 안드로이드 백버튼 = 뒤로 가기 또는 미니앱 종료.
- 터치·스크롤·화면 전환 반응이 2초 넘게 늦지 않다.
- 위치·알림 등 기기 권한은 먼저 동의를 받고, 거부해도 나머지 기능은 돌아간다.
- 네트워크·메모리 사용량이 갑자기 늘지 않는다.
- 불법·선정적 콘텐츠 없음.

**사용자 식별키**: 사용자 식별자를 확인해 저장하고, 사용 기록과 필요한 데이터가 종료 후 다시 들어와도 남아 있다.

## 비게임 전용

- 열리고, "앱 내 기능"에 소개한 기능이 모두 같게 동작한다. 등록한 스킴이 열리고, 스킴으로 들어온 뒤 뒤로 가기가 된다.
- **내비게이션 바**: 앱인토스 내비게이션 바를 쓴다. 뒤로 가기·홈·닫기가 모든 화면에서 동작한다. 최초 화면에서 뒤로 가기 = 종료. 토스 뒤로 가기와 자체 뒤로 가기를 동시에 보이지 않는다. 로고·이름은 앱 정보에 등록한 것만(자체 로고 추가 금지, 기본 로고·이름 제거는 가능). 미니앱 기능 버튼은 최대 1개. 더보기(⋯)에서 신고·공유 등 토스 공통 기능이 된다.
- 핀치 줌은 지도처럼 꼭 필요할 때만. 라이트 모드.
- 꼭 필요한 외부 링크만, 정상적으로 열린다. 공유 링크는 `intoss://` (`intoss-private://` 금지).
- 비속어·은어·과도한 유행어 금지.
- **토스 로그인을 쓰면**: 인트로에서 서비스 설명, 설정한 약관 URL이 보임, 토스에서 연결을 끊으면 다시 약관 화면 + 미니앱에 사용자 데이터가 남지 않음, 자사·기타 로그인 제공 금지.
- **토스페이를 쓰면**: 결제 중 음악 일시정지, 주문 금액 = 결제창 금액, 실패 사유 표시, 취소하면 이전·주문 화면으로, 다른 결제 수단 제공 금지.
- **배너 광고**: 상단·중앙·하단 중 적절한 곳, 스크롤되는 화면에만.

## 게임 전용

- 10초 안에 첫 화면이 열린다.
- 사운드: 무음 모드·진동 끔에서도 의도대로, 사용자가 켜고 끌 수 있음, 백그라운드로 가면 즉시 멈추고 돌아오면 다시 재생.
- 우측 상단 닫기 버튼이 보이고 동작한다. Safe Area(iOS Dynamic Island 포함)를 침범하지 않는다.
- 인게임은 풀스크린, 가로·세로 설정이 의도대로. 종료할 때 확인 모달. 점수·스테이지 같은 주요 흐름에 오류 없음.
- 랭킹·레벨·스테이지 기록이 유지된다.
- 배너 광고는 상단 또는 하단에만.
- 웹보드 게임: 성인 인증, 고객센터 문의 채널, 확률형 아이템 확률 공개.

## 인앱 결제 (공통)

음악 일시정지 · 주문 금액 = 구글·애플 결제창 금액 · 정상 진행(구글 테스트 환경 포함) · 완료 후 결과 반영 · 결제창에서 취소하면 주문 화면으로 · 잔액 부족 등 실패 사유 표시 · 결제 취소 처리 · 결제 내역 확인 가능 · 기기를 바꿔도 구매한 아이템·이용권 유지.

## 인앱 광고 (공통)

재생 중 음악 일시정지, 끝나면 다시 재생 · 토스 애즈 SSP 정책 준수 · 테스트 광고가 아닌 실제 광고가 끊김 없이 · **미리 로딩**(재생 시점에 실시간 로딩 금지) · 끝나면 미니앱으로 정상 복귀 · 리워드 광고를 끝까지 보면 보상 지급.

## 보도자료

- 배포 전 채널톡으로 토스팀에 사전 리뷰 요청.
- 제목 틀: `[서비스명], 토스 미니앱 출시` / `[법인명] [서비스명], 토스 미니앱 공식 론칭` / `[서비스명], 토스 미니앱 서비스 시작`.
- **쓰지 않는 표현**: 토스 공식 파트너사, 토스 입점사, 토스 제휴사, 토스 입점·토스 미니앱 입점. (`토스 미니앱 출시`는 가능)
- 용어: `앱인토스`는 파트너·시스템 쪽 명칭, 사용자에게는 `토스 미니앱`.
- 인용 가능한 수치: 토스 누적 가입자 3000만 명(2025-08 말), 월간 활성 이용자 2480만 명(2024 말).
- 앱인토스 로고는 `[회사명] | 앱인토스`처럼 막대(|)로 함께 표기, 파일은 채널톡으로 요청. 외부 광고는 별도 외부 광고 가이드.

## 저작권 침해 신고

- 신고가 형식 요건을 갖추면 **접수 즉시~1영업일 안에 미니앱이 임시 미노출**된다(침해 인정 아님, 저작권법 제103조).
- 파트너는 통보일부터 **30일 안에** 소명자료로 재개를 요구할 수 있다: 저작권·프로그램 등록증, 성명이 표시된 원본·최초 게시 기록·제작 파일, 라이선스 계약서·구매 영수증, 보호기간 만료 증빙.
- 앱인토스는 3일 안에 형식을 확인하고 재개예정일(접수 7일 뒤)을 정한다. 그 전에 신고자가 소송 증빙을 내면 미노출 유지, 없으면 복원.
- **예방**: 남의 글·그림·폰트·음원·캐릭터를 쓰지 않는다. 직접 만든 에셋은 원본 파일과 만든 날짜 기록(git 커밋)을 남겨 둔다. 라이선스가 있는 에셋은 라이선스 문서·영수증을 보관한다.
