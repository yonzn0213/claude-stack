## 개요

Salesforce 메타데이터 변경 · 삭제 전 역참조 전수 분석 스킬. 표준 "Where Is This Used?"가 탐지하지 못하는 Flow, 동적 SOQL, 문자열 리터럴, 리포트 참조까지 포함.

## 도입 배경

필드 삭제 후 배포는 성공하나 Flow · 동적 SOQL에서 런타임 오류가 발생하는 유형의 장애. 표준 기능만으로는 사전 탐지 불가.

## 설계

| 요소 | 내용 |
|---|---|
| 단어 경계 매칭 | `(^\|[^A-Za-z0-9_])` 경계 적용으로 부분 문자열 오탐 제거 (예: `AccountCode__c` 검색 시 `InputAccountCode__c` 제외) |
| 검색어 확장 | `__c` → `__r` 관계형, 문자열 리터럴, 라벨, 접두사 없는 이름 |
| 위험도 분류 | 메타데이터 유형별 배포 차단 / 런타임 위험 / 분류 미상 — 분류 미상은 커버리지 누락으로 간주해 `classify()` 보강 |
| org 보강 | 레포 미포함 항목(관리자 생성 Flow · 리포트 · 리스트뷰), 데이터 존재 여부를 읽기 전용 조회로 확인 |
| 보고 전용 | 참조 발견 시 수정하지 않고 판단을 사용자에게 위임 |

## 사용 범위

| 적용 | 비적용 |
|---|---|
| 필드 · 객체 · Apex 클래스 · LWC · 메서드 변경 및 삭제 전 영향 분석 | 요구사항 문서 수준의 영향 분석 |

## 운영 리스크

| 리스크 | 점검 신호 | 대응 |
|---|---|---|
| 신규 메타데이터 유형 미분류 | 분류 미상 결과 발생 | `classify()`에 확장자 추가 |
| 관리 패키지 네임스페이스 접두사 미반영 | 패키지 필드 검색 누락 | 검색어 확장 규칙 보강 |
| `rg` 미설치 환경 전제로 `grep -rE` 사용 | 대형 레포에서 스캔 지연 | `rg` 사용 가능 시 대체 |
